# 阵容配置与头像补录

## 操作步骤

1. 打开“金铲铲阵容配置工具”，选择当前赛季。
2. 点击“获取 MuMu 截图”或“导入截图”，然后“识别配置”。
3. 查看名称、追牌目标与图中星级。可拖框裁剪阵容区域后重新识别。
4. 若网格定位不合适，在“识别辅助 → 标定一个格子”框选第一行最左侧的完整六边形格子，再识别。
5. 选中一个或多个棋子，通过下方选单调整追牌目标。
6. 填写阵容名称并保存，无需选择路径。
7. 在商店助手中选择赛季、配置名称并“导入配置”。

上方同一行左侧为“1. 截图与识别”，右侧为“3. 阵容配置文件”；中部为预览和结果。
配置工具只读截图，不改变运行中的买牌列表。只有商店助手导入时，名单才会生效。

## 星级与追牌目标

| 图中星级 | 自动目标 | JSON 值 |
| --- | --- | --- |
| 一星 | 持续购买 | 0 |
| 二星 | 二星后移除 | 2 |
| 三星 | 三星后移除 | 3 |
| 未判定 | 持续购买，可手工调整 | 0 |

“未判定”不等于一星。星标裁掉、靠近图像上沿、模糊或样式超出当前模板覆盖范围，都可能导致未判定。
本模块只读静态阵容图中头像上方星标，不识别实战棋盘模型或持牌数量。
同名单位出现多次时自动取最高目标；手动修改过的条件在同一图片重新识别时保留。

## 头像识别与手工补录

最高相似度 **大于 60%** 时接受名称，不再要求与第二候选保持额外分差。
相似度是图像匹配分数，不是正确概率；导入前应核对名称。未知项必须修正或忽略才能保存。

有识别框但名称未知：

1. 选中该行，点击“修正名称／补录”。
2. 填写商店使用的正式名称，例如龙王应填“奥瑞利安·索尔”。
3. 勾选“同时保存头像，供下次识别使用”，确认。
4. 再次点击“识别配置”检查结果。

完全没有框时，使用“资源管理… → 框选并补录一个头像”，框住完整六边形头像后填名。
选择正确赛季；同名棋子支持多个模板。不同特殊模式可在资源管理中新建独立分区。

## 头像库维护

首次克隆不带完整头像库。先用资源管理中的 S16 官方更新或全部赛季公开导入建库。
公开源包括 CommunityDragon / Riot Data Dragon，以及金铲铲官网的公开静态数据。
导入报告及版本信息保存在本地 `data/portraits/`，不提交到 Git。

S16.5 已并入 `S16-海克斯典籍`，旧 `s16_5` 配置载入后对应 `s16`。
公共 TFT 资源只是参考，不代表全部金铲铲模式验证；不匹配时按需补录。

## 自动保存与导入

默认根目录为项目下的 `configurations/`。
S16 的《阵容x》保存到 `configurations/S16/s16_阵容x.json`；非法文件名字符替换为下划线。
覆盖同名配置时保留上一份有效 `.json.bak`。修改阵容名称相当于另存一个文件。
“打开阵容 JSON”可编辑已有文件，再保存时按当前赛季和阵容名称自动归档。

商店助手仅显示配置库中存在的赛季，配置选单显示文件里的阵容名称。
展开选单或点击导入会重新扫描，已打开商店助手时新保存的配置也可发现。
旧版平铺 JSON 兼容读取；同季同名同时存在时优先采用赛季子目录中的文件。
损坏 JSON 会跳过，不影响其他有效配置。

```json
{
  "schema": "jcc.lineup",
  "version": 1,
  "id": "unique-profile-id",
  "name": "阵容x",
  "season_id": "s16",
  "targets": ["蕾欧娜", "塔里克", "黛安娜"],
  "stop_rules": {"蕾欧娜": 3, "塔里克": 2, "黛安娜": 0},
  "slots": [],
  "source": "manual"
}
```

`targets` 是去重后的购买名称，不保存数量。`stop_rules` 是最终目标条件。
`slots` 可保存识别框、相似度、图中 `stars` 和初始 `stop_rule`，供编辑回看；最终条件以顶层为准。
旧配置没有 `stop_rules` 时，配置工具打开后默认补三星；商店助手直接导入时沿用当前默认值。
旧 `config.json` 保留兼容代码，但主界面不再提供独立的名单保存／载入按钮。
